# MoviePilot-Plugins

1. PT数据统计
- MoviePilot：`>=2.12.0`（V2 与 V3 共用同一实现和版本）V3 通过 MoviePilot 官方提供的 V2 插件向后兼容机制加载 `plugins.v2`。

2. 媒体库通知
- “媒体库通知”提供独立的 V2 2.x.x 与 V3 3.x.x 实现，支持 Emby、Jellyfin、Plex。极简配置可自定义的媒体库通知消息。

## 安装

同步插件市场的插件源或手动添加地址，刷新插件市场后搜索对应插件名

```text
https://github.com/changzhanghs/MoviePilot-Plugins
```
