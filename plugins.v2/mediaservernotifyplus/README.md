# 媒体库通知

面向 MoviePilot V2/V3 的 Emby、Jellyfin、Plex 媒体服务器通知插件。

## 版本

- MoviePilot V2：`2.1.4`
- MoviePilot V3：`3.1.4`
- 插件 ID：`MediaServerNotifyPlus`
- MoviePilot 通知类型固定为“媒体服务器”，消息渠道遵循 MoviePilot 全局设置。

## 配置界面

配置页采用左右工作台：左侧按媒体库、播放相关、账号与调试分组展示通知类型，右侧直接配置当前通知内容。“已标记”归入播放相关。每种通知可以独立启用或停用：

- 右侧按真实通知卡片排版显示固定示例封面、标题、媒体名称和字段值；勾选、改名、排序会实时更新预览，示例数据不会发送；
- 勾选需要展示的字段；
- 拖动调整字段顺序，触摸设备也可以使用上下移动按钮；
- 只允许修改字段展示名称，例如 `IP` 改为 `IP地址`；
- 字段没有真实值时自动隐藏整行。

右上角“设置”包含插件开关、媒体服务器选择、剧集入库聚合、去重及测试通知等全局选项。元数据按已勾选字段自动补查，IP 与归属地合并为同一个可选字段。

## 通知结构

事件标题和媒体名称为固定头部，不参与字段排序。例如：

```text
📂 已入库 1 个文件
兰香如故 (2026)

📺 季集：S01E21
🗂️ 媒体库分类：电视剧库
⭐ 评分：6.8/10
```

成功解析 TMDB ID 时，整张通知卡片跳转对应的 TMDB 电影或电视剧页面，不再单独展示 TMDB ID 和 TMDB 链接。

## 媒体服务器筛选

配置页读取 MoviePilot 中已启用的媒体服务器，可选择需要接收通知的 Emby、Jellyfin 或 Plex 实例。

## V2/V3 适配

- V2 使用 `NotificationType.MediaServer`、兼容 `tmdb_id` 以及 V2 媒体服务器帮助类。
- V3 使用公开 SDK、`MessageType.MediaServer` 以及 `media_source + media_id` 统一媒体身份。
- 两版共用通知字段、去重、聚合和媒体库筛选逻辑，并分别发布各自的 Vue 联邦配置界面。

## 默认通知图片

通知优先使用事件原图或已获取的媒体图片；没有图片时使用 `icons/mediaservernotifyplus-default.jpg`（用户提供的默认图）。登录和测试类型的示例通知也使用默认图。图片通过本仓库 `main` 分支的公开 Raw 地址传递给消息渠道，因此新默认图需随代码发布后才能被渠道读取。

去重时间设为 `0` 可关闭对应去重；账号事件按用户、IP、客户端、设备及会话区分。启用“停止时发送待聚合消息”后，保存重载或停止均会发送已入队的消息，旧运行中的事件在重载后失效。

## 删除图片与登录失败详情

删除通知独立补查对应 TMDB 作品图片，不受评分、演员、地区、简介等文字字段开关影响。剧集先使用整部剧的背景图，缺失时尝试海报；已删除条目的媒体服务器图片接口失效时不再继续使用，最终无图才回退默认图。

登录失败通知支持从原始 Webhook 的 `User`、`Session` 及认证信息中补全用户、IP、设备和客户端，并新增默认启用的“事件详情”字段，保留服务器发送的标题和说明。上游没有携带的数据仍按空字段隐藏。
