# PT数据统计

## 数据口径

- 上传、下载、分享率、魔力和做种数等主数据源仅为 MoviePilot 的 `SiteUserData`；不抓取 PT 站点、不读取下载器。
- 日期和通知 Cron 使用 MoviePilot 配置的服务器时区。
- 插件不设置独立采集间隔；MoviePilot 刷新站点后，插件通过 `SiteRefreshed` 事件读取其已保存结果。
- 当日上传/下载 = 当日累计值 − 严格前一自然日累计值；缺少前一天成功快照时显示“基线不足”。
- 累计值下降时负增量按 0 展示，不把更早日期当作前一天补算。
- 可选通过 PTD CookieCloud 备份补充“时魔”和“做种积分”；其他 PTD 字段一律不导入。未启用 PTD 时，预估时魔仍使用最近两次成功 MP 每日快照估算。
- 插件复制 MP 已保存的每日快照用于历史保留，不修改 MP 原始数据。
- PTD 导入数据使用固定存储键整体覆盖，只保留最新一份，不写入插件历史表；CookieCloud 本身也只提供当前备份。

## 功能

- **数据总览**：累计和今日指标、可整框点击选择月份/日期的站点上传下载分布，以及无需横向滚动的响应式站点卡片；加入时间只显示到日，魔力与预估时魔分别展示，并可按上传、下载、魔力、做种数或做种体积降序排列。
- **数据统计**：按日、周、月查看站点流量；点击站点后上方曲线切换为该站点数据，并在站点行内展开所选周期的历史明细。
- **养老进度**：十二大采用按真实加入时间排列的紧凑横向里程碑，已加入站点仅显示图标和名称，未加入节点保持匿名；左侧站点列表可独立滚动，右侧明细随内容完整展开并由页面统一滚动，集中展示当前上传、下载和分享率、对齐的保号等级路线、下一等级条件、保号目标与可展开的完整等级要求。注册时间到期后标记“注册时间已达成”。观众站以 Extreme User 为养老等级，按官方注册周数、累计下载、分享率和做种积分门槛展示完整规则与权限说明；MoviePilot 未提供做种积分时明确标记为数据未提供，不与魔力混算。没有可靠等级规则的站点显示“规则缺失”。
- **仪表板**：仅显示今日有有效上传或下载增量的站点，随 MP 卡片尺寸适配并支持内部滚动。
- **每日通知**：标准五段式 Cron；每个服务器自然日最多一次，不补发，无数据站点不通知。
- **数据导出**：设置页导出 UTF-8 CSV，支持日期、站点和字段选择。
- **PT 生涯**：设置页生成高清 PNG，可选择站点并自由隐藏汇总或站点字段。
- **PTD CookieCloud**：设置页填写 CookieCloud 地址、PTD 专用 UUID 和密码，跟随 MP 整轮站点刷新或顶部“数据刷新”读取当前 PTD 备份。PTD 备份需勾选“用户信息”，建议同时勾选“元数据”；支持 PTD 使用的 CookieCloud 加密格式。

所有用户可见页面、通知和导出均不展示站点域名。十二大按 MP 站点名称自动识别，不提供手工域名绑定。

## CSV 是什么

CSV 是用逗号分隔列的通用文本表格格式，Excel、WPS、Numbers 和多数数据库工具都能打开。本插件输出带 UTF-8 BOM 的 CSV，中文可直接识别。

## 构建前端

```shell
pnpm install
pnpm build
```

构建产物位于 `dist/assets`，模块联邦名称及后端插件类 ID 均为 `PTDataStatistics`。
